마이 미니홈피183 — 설치 순서 (이 순서대로만 하면 돼요)

[A] Supabase (한 번만)
 1. Supabase 프로젝트 > SQL Editor > New query
 2. schema.sql 내용을 전부 붙여넣고 Run
    → 방명록 / 다이어리·사진 저장 공간이 만들어져요.

[B] GitHub
 3. 이 폴더 안의 파일을 그대로 GitHub 저장소에 올려요.
    netlify/functions/minihome.js 경로가 꼭 유지돼야 해요.

[C] Netlify
 4. 저장소를 연결해 배포해요.
 5. Site configuration > Environment variables 에 4개를 만들어요.
    SUPABASE_URL = https://bcixligwqhlwvprayegh.supabase.co
    SUPABASE_SERVICE_ROLE_KEY = Supabase의 secret / service_role 키
    MINIHOME_OWNER_PASSWORD = 내가 정한 주인장 비밀번호
    MINIHOME_TOKEN_SECRET = 아무 긴 문자열 (32자 이상)
 6. 저장 후 Deploys > Trigger deploy 로 반드시 다시 배포해요.

[D] 사이트에서
 7. 기존 글/사진이 있던 브라우저에서 ♡ 일촌 > 주인장 모드 열기(비밀번호 = MINIHOME_OWNER_PASSWORD)
 8. '내 기존 사진·게시글 온라인으로 옮기기'를 한 번 누르고, '온라인 이전 완료'를 확인해요.
    (이전 전에는 브라우저 데이터를 지우지 마세요.)

주의: service_role 키는 GitHub 파일이나 채팅에 절대 넣지 마세요. Netlify 환경 변수에만 넣어요.
